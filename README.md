# 新加坡雾霾追踪

网站：https://doctoravis.github.io/sg-haze/

追踪 2026 年 9 月以来新加坡的跨境雾霾：

- 逐小时 24 小时 PSI、1 小时 PM2.5、全岛雨量和风向，以及降雨对空气质量的影响分析
- 印尼火点与烟霾的每日卫星图
- 未来 8 周的分段预判和情景概率

## 数据怎么更新

- 每天四次（新加坡时间 00:40、06:40、12:40、18:40 前后），GitHub Actions 自动更新历史数据和卫星图并重新发布网站。预判所用的预报每天更新一次。
- 页面上的“刷新数据”按钮会在你的浏览器里直接向 NEA 读取上次更新之后的最新读数，只在当前标签页生效。

## 来源

新加坡国家环境局 NEA / data.gov.sg、新加坡气象局 MSS、东盟专业气象中心 ASMC、NASA GIBS、Open-Meteo（ECMWF、SEAS5、ERA5、CAMS）、NOAA CPC。完整列表见网页底部。

分段预判、情景概率、输送风险指数和降雨事件识别都是本页按固定规则做的推算，不是官方预报。健康建议以 NEA 每日通报为准。
